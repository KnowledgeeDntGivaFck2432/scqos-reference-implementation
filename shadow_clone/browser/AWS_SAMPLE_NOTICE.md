# AWS sample attribution

The browser container and connection helpers are derived from
`aws-samples/sample-playwright-cli-browser-agent-on-bedrock-agentcore` at commit
`0c04fb491cd981db464618108bfb770d0f41a0ad`, licensed under MIT-0.

The upstream project describes itself as experimental. Shadow Clone pins the
observed dependency versions and subjects the resulting container digest and
deployment receipt to SCQOS verification; production qualification remains an
explicit deployment step.
